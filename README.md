# Mudammild — Digital Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/` — put your photos, certificates and thumbnails here

## Before publishing
1. Replace the `M` portrait placeholder in `index.html` with your profile photo.
2. Replace `YOUR_EMAIL@example.com`.
3. Replace the Instagram, LinkedIn and GitHub `#` links.
4. Add the real TikTok link for “POV Sakit di Dayah”.
5. If desired, add thumbnails from your actual videos in the `assets` folder.
6. Open `index.html` in VS Code / Live Server to preview.
7. Publish the folder with GitHub Pages when ready.

## Editing
Everything is plain HTML/CSS/JavaScript, so you can change text, links, colors and sections later without rebuilding the site.


## Certificates
Eight certificate images are included in `assets/` and displayed as clickable cards with a full-screen preview.

## Video files
- YouTube projects are embedded directly in the Works section.
- `assets/personal-video-project.mp4` is the uploaded unpublished personal project.
- Add your direct TikTok URL to the POV project card when available.
